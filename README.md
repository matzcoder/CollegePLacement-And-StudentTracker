## 🎓 College Placement Drive & Student Application Tracker

> A full-stack placement management system built for **SIH 2026**, designed to streamline placement drives, student applications, recruitment workflows, and AI-assisted placement queries.

The platform replaces manual Excel sheets, WhatsApp forwards, and scattered email updates with one centralized, role-based placement workspace.
